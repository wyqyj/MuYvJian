# 暮雨笺

> v3.0.8 新增安全的 AI 写作与学习助手，可在笔记中生成摘要、提纲、复习卡片和润色建议。

> [查看完整更新告示](UPDATE_NOTICES.md)，按版本集中记录每次功能、修复和发布变化。

融合记事本、待办管理与快速随笔记的桌面应用，支持 Markdown 和 LaTeX 实时渲染。提供简体中文与古风两种文字风格。

荧光与月光缠绕，时光在指尖沉淀

是古典是简素，在你的笔下流转

不必懂得复杂编译，你只需自由书写

毕业快乐。从此山高水长，愿这封「暮雨笺」陪你看代码化作公式，等灵感落成春雨。

## 功能

### 便签管理
- 新建、搜索（结果高亮）、标签多选筛选、归档、回收站
- 标签下拉选择已有标签，支持全局置顶和标签内独立置顶
- 截止日期倒计时，便签排序（更新时间/创建时间/标题/截止日期）

### 编辑器
- CodeMirror 6 语法高亮、自动换行、查找替换（Ctrl+F/Ctrl+H）
- 快捷键：Ctrl+B 加粗、Ctrl+I 斜体、Ctrl+K 链接
- 插入图片（工具栏选择、粘贴、拖拽）
- 笔记链接 `[[标题]]` 点击跳转
- 代码块语法高亮（16 种语言）

### 待办系统
- 独立待办便签，批量添加任务（每行一个）
- 每任务独立截止时间倒计时
- 每任务正向计时（秒表），记录用时数据
- 任务统计窗口：今日/本周/本月用时饼状图和时间线
- 未完成待办自动置顶，全部完成变灰
- 悬浮窗口查看，支持透明度调节

### 快速笔记
- `Alt+Q` 呼出悬浮速记小窗口
- 关闭时自动保存为便签，支持编辑/预览/分栏模式

### 无限画布与素材
- 可创建多个独立画布，在侧栏与便签统一管理
- 自由放置、编辑、缩放文字块、图片和关联笔记卡片；连续添加的元素会自动错位摆放
- 支持拖放、粘贴或从本地素材库放入图片；素材可跨画布复用
- 支持拖拽平移、滚轮缩放、网格吸附、键盘删除、画布模板和元素关系连线
- 项目拆解、阅读研究、周复盘三种模板可快速搭建结构
- 双击关联笔记卡片即可回到原始笔记；笔记反向链接会显示引用它的画布

### 学习工作台
- 考研倒计时、阶段规划、今日任务、逾期顺延与月综合任务
- 可暂停和结束的专注计时，按科目统计学习时长，并导出学习打卡图片
- 数学、英语、政治、业务课默认书架，可自定义书架分组并使用系统默认程序打开托管书本
- 题册/错题 Markdown 导入、章节树、题目画布、正确/错误/待重做/已通过筛选和重点标签题册导出
- 题册支持按全部题目、当前筛选或当前章节指定数量导出 PDF
- 规划支持导入 `- [ ] 任务名称` / `- [x] 任务名称` Markdown 任务清单
- 工作台内置笔记与无限画布一级模块，直接复用 Markdown 渲染、图片、关联笔记、版本历史和素材库
- 可改动本地数据目录，目录迁移经过 SHA-256 校验；综合备份为单个 `.muyujian-workspace` 文件
- 设置支持初始化全部数据，恢复功能、Markdown、公式和版本更新预置笔记，并清理工作台内备份；工作台根目录位置保持不变

### 工作台文件案例

每个工作台模块均有对应案例文件，索引见 [examples/workbench/README.md](examples/workbench/README.md)。

- 规划：`examples/workbench/plans/weekly-plan.md`，可从“规划”页导入
- 题册：`examples/workbench/question-books/calculus-volume-1/questions.md`，可从“题册”页导入
- 笔记、画布、书架、专注、设置与备份均提供 JSON 或 Markdown 结构案例
- 外部 Agent 整理题目时应遵循 `skills/muyujian-question-book-import/SKILL.md`

### 任务看板与历史
- 待办便签可在待处理、进行中、已完成三列之间拖拽流转
- 看板卡片显示子任务完成度和截止日期，双击可回到原始待办
- 笔记和画布自动保留最近 20 个版本快照，支持按时间恢复

### 全局操作
- `Ctrl+K` 命令面板可搜索笔记、画布文本和常用操作
- 顶部素材库集中管理本地图片，导入后可直接插入画布
- 外观面板支持上传、替换和清除本地壁纸

### 导出
- 支持 Word、PDF、Markdown、HTML、纯文本格式
- PDF 导出需系统安装 LaTeX 发行版（如 MiKTeX）

### 界面
- 浅色/深色主题切换
- 简体中文/古风文字切换
- 预览面板显示/隐藏（Ctrl+Shift+P），也可通过关闭按钮、命令面板或外观面板手动关闭
- 专注模式（F11），沉浸写作

### LaTeX 公式
- KaTeX 实时渲染，支持 `$...$` 行内和 `$$...$$` 块级公式
- 支持 equation/align/gather 等数学环境

### 数据安全与迁移
- 回收站：删除的便签可恢复，30 天自动清理
- 自动保存：内容更新即时持久化，退出时立即保存
- 任务计时数据持久化到本地文件
- 数据备份包含偏好设置、壁纸、笔记、版本历史、无限画布、素材库和任务计时记录，支持完整迁移

## 快速开始

```bash
# 安装依赖
npm ci

# 开发模式启动
双击「启动暮雨笺.bat」

# 或手动构建并启动
npm run build
npx electron .
```

## 打包为安装程序

```bash
双击「打包.bat」
```

打包脚本会先构建生产文件到临时目录；新安装包生成成功后才替换旧的 `release` 输出，因此 `release` 始终只保留最近一次成功的 v3.0.8 发布版本。启动脚本不会清除笔记、设置或学习工作台数据，也不会结束其他 Electron 应用。

打包使用 `node_modules/electron/dist` 准备本地 Electron 运行时到 `electron-dist-local/`，该目录为本机构建缓存并已被 Git 忽略；首次打包前只需完成 `npm ci`。

维护者可从 [MAINTENANCE_GUIDE.md](MAINTENANCE_GUIDE.md) 查看功能到代码文件的索引、数据边界、测试与发布检查清单。

`dist`、`release`、`node_modules` 与本地工作台备份均为可再生或用户私有数据，已由 `.gitignore` 排除，不应提交到 GitHub。

> 注意：pandoc.exe 未包含在 git 仓库中（超过 GitHub 文件限制），打包前请确保 `resources/pandoc/pandoc.exe` 存在。
